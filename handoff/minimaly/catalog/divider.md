# Divider

Horizontal rule with a centered label, for a break in a feed or a list.

```html
<div class="divider"><span>NEW MESSAGES</span></div>
<div class="divider" data-variant="quiet"><span>Yesterday</span></div>
```

- Default (accent) marks something to notice: unread, now. `quiet` marks a plain separation: a date, a group.
