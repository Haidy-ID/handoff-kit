# Minimaly

Quiet tool UI for handoff pages, internal tools and prototypes. Neutral zinc surfaces, ink (black, white in dark) for the main action and chosen states, one blue accent for focus, links and what is active or current, violet reserved for AI agent identity, mono type for data, codes and labels.

- Import: `@import "<path>/handoff/minimaly/ds.css";`. Pages with icons or with any behaviour (tooltips, selects, segmented, tabs, menus, dialogs, toasts, async and hold buttons, values, skeletons, streams, steps, progress, pagination, sortable tables, scroll spy, sticky header) also load `ds.js` after the content. Each card says when it needs it.
- Tokens: `tokens.css`. Use the semantic roles only (`--color-surface*`, `--color-text-*`, `--color-border*`, `--color-ink`, `--color-on-ink`, `--color-accent*`, `--color-agent*`, `--color-brand`, `--color-status-*`), never the primitives (`--neutral-500`…). Sizes: `--font-size-*`, `--spacing-*`, `--radius-*`, `--shadow-*`, `--control-height`, and the fixed sizes `--size-mark` (16 px status marks), `--size-icon-sm` (12 px icons), `--size-row` (40 px rows), `--size-bar` (56 px top bars).
- Dark: `html[data-theme="dark"]`.
- Motion: `--duration-fast` (hover, press), `--duration-base` (tooltip, popover), `--duration-slow` (entrances, crossfades), `--duration-stagger`, `--ease-out`, `--ease-in`, `--ease-spring`. Shared keyframes in `components.css`: `enter`, `enter-down`, `pop-in`, `fade-in`, `fade-out`, `spin`, `blink` (`animation: enter var(--duration-slow) var(--ease-out) both`). Components already move: buttons press, tooltips and popovers pop in, the segmented indicator slides, focus rings and the select caret ease. `--duration-flash` lights a changed value, `--delay-show` keeps a skeleton silent. Timings of tooltips, async buttons, values and skeletons follow interior.dev. Springs: `--ease-spring` (3 % overshoot, for things that move or resize) and `--ease-bounce` (16 %, for small things that pop), always with `--duration-spring`. Content swapping in place (labels, panels, digits) passes through `--blur-swap` (keyframe `swap-in`); an error plays `shake` once when it appears (refused value, failed step, async button error, critical toast or banner); a persistent critical tone never shakes. Tooltips, popovers, menus and dialogs open and close natively (`@starting-style`, discrete `display`), from the side of their trigger. Pages of the same site crossfade on navigation (`@view-transition`). Reduced motion sets every duration to 0.
- Components: `button`, `badge`, `chip`, `avatar`, `kbd`, `card`, `divider`, `tooltip`, `popover`, `input`, `select`, `segmented`, `breadcrumb`, `accordion`, `icon` (Phosphor), `async-button`, `value`, `skeleton`, `tabs`, `menu`, `dialog` (modal, drawer), `toast`, `stream`, `typing`, `steps`, `progress`, `pagination`, `table`, `toc`, `sticky-header`, `hold-button`, `field`, `checkbox`, `radio`, `switch`, `textarea`, `banner`, `empty`, `list`, `shell`, `composer`, `reasoning`, `tool-call`, `cite`, `dropzone`, `stepper`, `combobox`, `rich-editor`, `date-picker`, `command-palette`, `attachment`, `slider`. `stream`, `typing` and the active step are violet: they show the agent at work. Read the card of each one you use before writing markup.
- Disabled, for every component: the default look at 40% opacity (`opacity: 0.4`), no color change.
- Anything clickable is at least 32 px high (`--control-height`). Badges and chips are labels, never clickable: a clickable filter is a `.btn` with `aria-pressed`.
