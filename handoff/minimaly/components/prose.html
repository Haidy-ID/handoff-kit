Offline first, for real

Researchers spend weeks without a signal. The app had to treat the network as a rare event, not a given: every write lands on the device first, then syncs.

  • Writes never wait for the network.
  • Conflicts merge field by field, not note by note.
  • A sync badge says what is still local.
// A note merges per field: the latest edit of each field wins.
const merged = { ...older, ...pickNewest(older, newer) };

“It is the first app that did not lose a day of my notes.”

Ana, botanist, after six weeks in the Azores
